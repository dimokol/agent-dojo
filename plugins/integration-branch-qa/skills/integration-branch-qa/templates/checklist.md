# QA checklist

What to test by hand on the integration branch. One section per PR with 1 to 3 items, written for the person testing: what to click and what should happen. Each heading names its PR, like `## #42: new sign-up form`, because `qa-branch.sh check-pr 42` counts the unticked boxes under every heading that names #42. A section leaves once all its boxes are ticked and the PR has merged.

Tick boxes in a browser with `qa-branch.sh checklist`. Restart the dev servers after each rebuild.
